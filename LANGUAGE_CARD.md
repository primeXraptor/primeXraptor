# Language card setup

The README uses `assets/top-languages.svg`, generated by the **Refresh language card** GitHub Actions workflow every six hours or with **Run workflow**. Scheduled runs can be delayed by GitHub. This is a periodically refreshed snapshot, not a real-time service. GitHub can cache README images briefly. GitHub disables scheduled workflows in inactive public repositories after 60 days; re-enable the workflow if necessary.

1. Create a fine-grained personal access token for **primeXraptor**, selecting **all repositories** (including private repositories) with read access to repository **Metadata**. This is needed for listing repositories and reading their language breakdowns. If using selected repositories instead, the card will only include those repositories; GitHub does not reveal omitted repositories to the script. Organization repositories are excluded from this personal profile summary.
2. In this repository's **Settings → Secrets and variables → Actions**, add a repository secret named `PRIVATE_STATS_TOKEN`. Never put the token in source files or chat. The default `GITHUB_TOKEN` cannot read your other private repositories. Renew the secret when the token expires.
3. Push these changes, then open **Actions → Refresh language card → Run workflow**. The job also runs when its script or workflow is pushed to `main`. The job uses `GITHUB_TOKEN` only to commit the card; the personal token is used only for API reads. Repository rules must allow the workflow's push to `main`.
4. Confirm the job succeeds and the card displays its UTC update time. Until then, the placeholder intentionally shows no percentages.

Percentages use GitHub Linguist's language **byte counts**, across all accessible repositories owned by this account, including archived and private repositories and excluding forks. The top six languages are shown with the remainder grouped as Other. This measures source language composition, not frameworks, runtime usage, or commit activity. GitHub may take time to update its own language analysis.

Only aggregate percentages, language names, and the refresh time are published. Repository names and raw API responses are not saved. Aggregate data from private code will be publicly visible in the SVG and its Git history. The job fails rather than overwriting the card if API reads fail or no private repositories are visible. Partial repository access cannot be detected reliably: ensure the token covers all intended repositories.

Local checks (no token needed): `python3 -m unittest discover -s scripts -p 'test_*.py'`. To refresh locally, supply `PRIVATE_STATS_TOKEN` securely in the process environment and run `python3 scripts/update_languages.py`.
